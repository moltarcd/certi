# 🧠 QA Agent Autónomo

Framework de pruebas API con generación automática de casos, análisis de impacto y ejecución offline.

## 🚀 Iniciar

```bash

python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python web_launcher.py

```


## Cada vez que quiera actualizar las dependencias por si se instalan 
```bash
pip freeze > requirements.txt

```
